## 有哪些玩法？

- 1～4位真人，缺位电脑补齐，可指定对家。
- 手动进贡还贡、内贡、抗贡与打 A 房规。
- 小牌提示、10/15/30秒超时代打或关闭。
- 自定义昵称头像、本地音乐音效、语音短句和表情。
- 本机战绩、段位及真人/人机/练习分榜。
- 8～32人团建赛事，积分赛到淘汰赛及决赛；联机试用采用队长手动录分、双方确认。

## 离线怎么玩？

首次打开及更新需联网完成缓存。缓存后单人练习可以离线；朋友联机需连接同一个支持设备互连的 Wi-Fi 或热点，双向配对，可尝试不耗外网流量。当前网页版没有蓝牙联机；没有可用局域网时，请使用单人练习。

iPhone 建议 Safari；微信扫码、不同热点、手机后台及大型团建的兼容性仍需实测。公开试玩版，尚未完成全部真机验收。截图来自真实浏览器测试页面，不代表真机验证。
